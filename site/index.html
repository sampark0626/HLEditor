01촬영

카메라가 알아서
공을 따라가요

삼각대에 세우고 녹화 버튼만 누르면 끝이에요. 그런데 “카메라가 어디를 보고 있는가”가 하이라이트를 찾는 단서가 돼요.

  • 골문 앞에서 멈추면 → 득점 기회카메라가 한쪽 골대 앞에 머무는 순간에 가산점을 줘요.
  • 빠르게 휙 돌면 → 역습카메라가 움직이는 속도도 장면을 읽는 신호예요.
  • 30분씩 끊긴 파일도 한 경기로녹화 시작 시각과 길이로 이어 붙일 파일을 알아서 찾아요.

02자동화 여정

사람은 세 번,
나머지는 자동이에요

촬영부터 BAND에 올리기 직전까지. 서버 한 대 없이 Google Drive · Apps Script · Kaggle · YouTube · ntfy를 이어 붙였어요.

  1. 01촬영 사람

    삼각대에 카메라를 세우고 녹화 버튼을 눌러요.

  2. 02폰으로 업로드 사람

    Drive 앱으로 00_upload에 올리고, 다 올라가면 01_inbox로 옮겨요.

  3. 03영상 발견 자동

    Apps Script가 일·월요일엔 5분마다, 평소엔 1시간마다 폴더를 보고 영상이 있으면 Kaggle을 켜요.

  4. 04분석과 편집 자동

    Kaggle 노트북이 영상을 이어 붙이고, 소리·카메라 움직임·AI로 장면을 골라 하이라이트를 만들어요.

  5. 05YouTube 업로드 자동

    제목, 득점 챕터, 썸네일까지 붙여서 올려요.

  6. 06알림 → BAND 사람

    알림이 한 통 오면 눌러서 복사하고, BAND에 붙여넣으면 끝이에요.

    경기_1.mp4
  4. 03_done

04AI 판별

싼 것부터 거르고,
비싼 건 마지막에

AI의 눈
